MovieLife 현재 프로젝트 수정본 (20260915-3)

적용 방법
1. 실행 중인 MovieLife 서버를 정지합니다.
2. Eclipse/STS에서 실제 실행하는 프로젝트를 우클릭 → Properties → Resource → Location으로 실제 폴더를 확인합니다.
3. 기존 프로젝트는 백업해 둡니다.
4. 이 압축을 별도 폴더에 완전히 풉니다. 압축 내부를 탐색하는 상태에서 실행하지 마세요.
5. 압축을 푼 movielife 안의 src 폴더를 2번에서 확인한 프로젝트 폴더에 복사하고 같은 파일을 덮어씁니다.
   최종 경로: 프로젝트/src/main/resources/static/js/account.js
   src/src 또는 main/main으로 중첩되지 않아야 합니다.
6. Eclipse/STS에서 프로젝트 선택 → F5 → Project 메뉴 → Clean → 해당 프로젝트 선택.
7. MovieApplication을 다시 실행합니다. 브라우저에서 Ctrl+F5로 새로고침합니다.
8. 회원가입 페이지 소스 보기(Ctrl+U)에서 20260915-3을 검색하면 적용 여부를 확인할 수 있습니다.

수정 내용
- 관련 14개 화면에서 공통 auth-header.js를 화면별 스크립트보다 먼저 한 번만 실행.
- JS URL에 새 버전 표시를 붙여 이전 캐시와 구분. 공통 스크립트 중복 초기화 방지.
- 로그인 후 /api/members/me로 세션 확인 → 중앙 완료창 → 원래 화면 복귀.
- 회원가입 중복확인과 검증, 중앙 완료창 복구. 확인을 누른 뒤 로그인 이동.
- account.js에서 빠졌던 프로필 수정·마이페이지 활동·회원탈퇴 처리 복구.
- 공통 ML을 사용하는 리뷰/찜/OTT의 초기화 순서 통일.
- OTT 연결 실패/인증 실패를 오류 메시지로 전달하고 재시도 제공.
- 기존 국내/해외/추천 기능 구현, DB 설정과 회원 데이터는 수정하지 않음.

확인 범위
실제 JS를 모의 DOM/API에서 실행하여 로그인/헤더, 가입 완료창, 탈퇴, 리뷰 등록,
찜 추가/취소, OTT 오류/재시도 테스트 통과. 공통 요청 21개 검사 통과.
14개 화면 스크립트 경로/순서, JS 문법, Java 27개 파일 문법 검사 통과.
실제 Spring Boot 빌드·브라우저 렌더링·사용자 DB/TMDB 연결은 이 환경에서 검증하지 못했습니다.
TMDB 인증 오류가 표시되면 실제 서버의 API 키 확인이 별도로 필요합니다.

실행 중 오류가 남으면
브라우저 Console의 오류 문구와 Network의 실패 요청 상태 코드를 보내주세요.
비밀번호나 API 키는 보내지 마세요.
