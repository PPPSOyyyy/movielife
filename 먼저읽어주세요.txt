movieLife 디자인/기능 정리본

1. 디자인만 먼저 확인하기
   docs 폴더의 preview-home.html을 더블클릭하세요.
   화면 위 링크로 영화 목록/상세/마이페이지/로그인/회원가입 디자인을 볼 수 있습니다.
   예시 데이터이며, 이 파일에서는 실제 로그인·DB 저장이 되지 않습니다.
   docs 폴더와 src 폴더의 위치를 그대로 유지해 주세요.

2. 기존 STS 프로젝트에 적용하기
   (1) 실행 중인 Spring Boot를 중지하세요.
   (2) 현재 프로젝트 폴더를 먼저 복사하여 백업하세요.
   (3) 이 압축파일은 보내주신 movielife(3).zip 기준의 전체 소스입니다.
       그 이후 팀원 코드가 바뀌었다면 docs/CHANGES.md의 변경 파일 목록을 기준으로 병합하세요.
       이후 변경이 없다면 압축을 푼 movielife 폴더의 내용을 기존 프로젝트 폴더에 덮어쓰시면 됩니다.
   (4) src/main/resources/application.properties에서 기존 DB/TMDB 연결 설정을 확인하세요.
       보내주신 설정값은 유지되어 있습니다. DB를 삭제하거나 새로 만들 필요는 없습니다.
   (5) STS에서 프로젝트 우클릭 → Gradle → Refresh Gradle Project를 실행하세요.
   (6) MovieApplication.java를 Run As → Spring Boot App으로 실행하세요.
   (7) 브라우저에서 http://localhost:8080 을 열고 Ctrl+F5로 새로고침하세요.

3. 팀원 담당 영역
   국내/해외영화의 실제 조회 기능은 구현하지 않았습니다.
   클릭 시 준비 중 화면만 표시하며, 팀원이 구현할 때 TeamPageController.java의 해당 매핑을
   삭제하거나 교체하면 됩니다. 같은 주소를 두 컨트롤러에 동시에 만들면 안 됩니다.
   영화추천은 기존 본문과 추천 스크립트를 유지하고 공통 헤더만 연결했습니다.

4. 검증 범위
   Java 17 문법 검사, JS 문법 검사, 입력 검증 18건, 클라이언트 로직 21건,
   템플릿/정적 파일/공통 화면 부품 연결 검사를 완료했습니다.
   이 작업 환경에서는 Gradle 다운로드와 로컬 브라우저 접근이 제한되어
   전체 Gradle 빌드, 실제 Thymeleaf 렌더링, MySQL/TMDB 통합 실행, 브라우저 외관 검증은 완료하지 못했습니다.
   포함된 JUnit 테스트는 의존성 다운로드가 가능한 컴퓨터에서 실행해 주세요.

5. 테스트 실행 (프로젝트 폴더의 터미널에서)
   Windows: gradlew.bat test
   Mac/Linux: bash gradlew test
   Node.js 18 이상이 있다면: node scripts/check-client.cjs

자세한 변경 내역과 실행 후 확인 순서는 docs/CHANGES.md에 있습니다.
